# Flow Import/Export for Flow Editor

Adds Import and Export buttons to the flow editor palette panel, enabling users to download the current flow as JSON and upload a JSON file to visualize a flow on the canvas.

The export serializes the current canvas to the engine tree format (what gets stored in the DB) and triggers a download. The import validates the JSON structure before converting and displaying. On validation failure, the canvas remains unchanged and an error message appears. The implementation reuses the existing `treeToCanvas`/`canvasToTree` serializer and follows existing UI patterns (Strapi design system buttons, inline error text).

**Watch for:** No unit tests were written for the import validation logic despite the plan calling for them (possible, needs verification if coverage is desired).

**Verdict**: APPROVED

## High-level view

The export path builds a `CanvasGraph` from current ReactFlow nodes/edges, passes it through `canvasToTree`, and triggers a blob download. A silent catch handles the case where no trigger root exists (nothing to export). The import path uses a hidden file input, reads the file via FileReader, validates structure (object with string id, string type, trigger root), then passes through `treeToCanvas` to populate the canvas. On any failure, `setImportError` displays inline text and the canvas is untouched.

The UI adds an "Import / Export" section at the top of the palette panel with two secondary variant buttons using Upload/Download icons from @strapi/icons. A separator now divides this section from the existing "Palette" section. The buttons respect the `disabled` prop.

The plan called for a dedicated `import-export.test.ts` file but none was created. The validation logic is inline and straightforward, and the serializer it delegates to is already well-tested (serialize.test.ts). The coder's verification evidence shows 275 tests passing.
